START
  │
  ├─→ [INPUT PARAMETERS FROM FRONTEND]
  │   │
  │   └─→ Input: JSON/Dictionary object containing:
  │       │
  │       ├─→ store_code: String (e.g., "RHN", "HBT", "HDG", etc.)
  │       │
  │       ├─→ store_target: Number (store's revenue target)
  │       │
  │       ├─→ store_fp_ratio_target: Number (target full-price ratio, e.g., 0.7 for 70%)
  │       │
  │       ├─→ query_date: Object {
  │       │   ├─→ from_date: Date (start date for query period)
  │       │   └─→ to_date: Date (end date for query period)
  │       │   }
  │       │
  │       └─→ employees: Dictionary/Array of employee objects [
  │           {
  │             ├─→ employee_code: String (unique employee identifier)
  │             ├─→ full_name: String (employee's full name)
  │             ├─→ seniority: Number (tenure in years)
  │             ├─→ personal_target: Number (employee's personal sales target)
  │             ├─→ working_day_count: Number (days worked in the period)
  │             ├─→ is_manager: Boolean (true if employee is store manager)
  │             └─→ is_probation: Boolean (true if employee is on probation)
  │           },
  │           ...
  │         ]
  │
  ├─→ [DERIVED/CALCULATED PARAMETERS]
  │   │
  │   ├─→ total_employee_count = COUNT(employees)
  │   ├─→ total_working_days = SUM(all employee.working_day_count)
  │   ├─→ actual_revenue (queried from database for the period)
  │   ├─→ actual_full_price_revenue (queried from database)
  │   ├─→ actual_discounted_revenue (queried from database)
  │   └─→ employee sales data (queried per employee, filtered by store in Step 2.1)
  │
  ├─→ [STEP 1] Check Store Eligibility & Calculate Achievement
  │   │
  │   ├─→ Calculate achievement_pct = (actual_revenue / store_target) × 100%
  │   │
  │   ├─→ Calculate actual_fp_ratio = (actual_full_price_revenue / actual_revenue) × 100%
  │   │
  │   └─→ IF (actual_fp_ratio < store_fp_ratio_target)
  │       └─→ Check discounted goods compensation
  │           │
  │           ├─→ fp_shortage = (store_fp_ratio_target - actual_fp_ratio) × actual_revenue
  │           ├─→ required_discounted = fp_shortage × 200%
  │           │
  │           └─→ IF (actual_discounted_revenue < required_discounted)
  │               └─→ RETURN "Not eligible for commission"
  │
  ├─→ [STEP 2] Calculate Each Employee's Contribution to Store Pool
  │   │
  │   └─→ FOR EACH employee IN employees
  │       │
  │       ├─→ [2.1] Filter Employee Sales by Store
  │       │   │
  │       │   │   // IMPORTANT: Only include sales from employee's assigned store
  │       │   │   // Exception: RHN and RWP are considered the same store
  │       │   │
  │       │   ├─→ Query employee sales data for the period (from_date to to_date)
  │       │   │
  │       │   └─→ Filter sales transactions:
  │       │       │
  │       │       ├─→ IF (store_code == "RHN" OR store_code == "RWP")
  │       │       │   └─→ Include transactions where transaction.store IN ["RHN", "RWP"]
  │       │       │
  │       │       └─→ ELSE
  │       │           └─→ Include transactions where transaction.store == store_code
  │       │       │
  │       │       ├─→ employee.fp_revenue = SUM(filtered full-price sales)
  │       │       └─→ employee.disc_revenue = SUM(filtered discounted sales)
  │       │
  │       ├─→ [2.2] Determine Employee Tier Category Based on Seniority
  │       │   │
  │       │   ├─→ IF (employee.seniority >= 3 years)
  │       │   │   └─→ employee.tier_category = "Senior" (3+ years)
  │       │   └─→ ELSE
  │       │       └─→ employee.tier_category = "Junior" (< 3 years)
  │       │
  │       ├─→ [2.3] Define Commission Rate Structure (CUMULATIVE)
  │       │   │
  │       │   │   // IMPORTANT: Commission rates are ADDITIVE across tiers
  │       │   │   // Higher achievement means earning ALL lower tier rates PLUS the current tier rate
  │       │   │   // Exception: Tier 100%+ rates ONLY apply to revenue EXCEEDING 100% target
  │       │   │
  │       │   ├─→ Tier 70-80% Rates:
  │       │   │   ├─→ Full Price Rate = 0.5% (applies to all employees)
  │       │   │   └─→ Discounted Rate = 0.25% (applies to all employees)
  │       │   │
  │       │   ├─→ Tier 80-90% Rates:
  │       │   │   ├─→ IF (employee.tier_category == "Senior")
  │       │   │   │   └─→ Full Price Rate = 0.2% (ON TOP of Tier 70-80% rates)
  │       │   │   └─→ ELSE IF (employee.tier_category == "Junior")
  │       │   │       └─→ Full Price Rate = 0.1% (ON TOP of Tier 70-80% rates)
  │       │   │   └─→ Discounted Rate = 0% (not applicable)
  │       │   │
  │       │   ├─→ Tier 90-100% Rates:
  │       │   │   ├─→ IF (employee.tier_category == "Senior")
  │       │   │   │   └─→ Full Price Rate = 0.2% (ON TOP of previous tier rates)
  │       │   │   └─→ ELSE IF (employee.tier_category == "Junior")
  │       │   │       └─→ Full Price Rate = 0.1% (ON TOP of previous tier rates)
  │       │   │   └─→ Discounted Rate = 0% (not applicable)
  │       │   │
  │       │   └─→ Tier 100%+ Rates (SPECIAL RULE):
  │       │       ├─→ IF (employee.tier_category == "Senior")
  │       │       │   └─→ Full Price Rate = 0.1% (ONLY on revenue EXCEEDING 100% target)
  │       │       └─→ ELSE IF (employee.tier_category == "Junior")
  │       │           └─→ Full Price Rate = 0.05% (ONLY on revenue EXCEEDING 100% target)
  │       │       └─→ Discounted Rate = 0% (not applicable)
  │       │       │
  │       │       └─→ NOTE: The 100% target portion uses Tier 90-100% rates
  │       │
  │       ├─→ [2.4] Calculate Commission for Each Tier
  │       │   │
  │       │   ├─→ commission_tier_70_80 = 
  │       │   │   ├─→ (tier_70_80.fp_revenue × 0.5%) +
  │       │   │   └─→ (tier_70_80.disc_revenue × 0.25%)
  │       │   │
  │       │   ├─→ commission_tier_80_90 = 
  │       │   │   └─→ tier_80_90.fp_revenue × (0.2% if Senior OR 0.1% if Junior)
  │       │   │
  │       │   ├─→ commission_tier_90_100 = 
  │       │   │   └─→ tier_90_100.fp_revenue × (0.2% if Senior OR 0.1% if Junior)
  │       │   │
  │       │   └─→ commission_tier_100_plus = 
  │       │       └─→ tier_100_plus.fp_revenue × (0.1% if Senior OR 0.05% if Junior)
  │       │
  │       └─→ [2.5] Sum Total Employee Contribution
  │           │
  │           └─→ employee_contribution = 
  │               ├─→ commission_tier_70_80 +
  │               ├─→ commission_tier_80_90 +
  │               ├─→ commission_tier_90_100 +
  │               └─→ commission_tier_100_plus
  │
  ├─→ [STEP 3] Calculate Total Store Pool
  │   │
  │   └─→ store_pool = SUM(all employee_contributions across all employees)
  │
  ├─→ [STEP 4] Distribute Store Pool to Each Employee
  │   │
  │   └─→ FOR EACH employee IN employees
  │       │
  │       ├─→ [4.1] Calculate Individual Share (70% based on contribution)
  │       │   └─→ individual_share = 70% × employee_contribution
  │       │
  │       ├─→ [4.2] Calculate Equal Share (30% pool distribution)
  │       │   │
  │       │   ├─→ IF (store_code in ("RHN","RWP"))
  │       │   │   └─→ // RHN, RWP: Distribute based on working day contribution
  │       │   │   └─→ working_day_ratio = employee.working_day_count / total_working_days
  │       │   │   └─→ equal_share = 30% × store_pool × working_day_ratio
  │       │   │
  │       │   └─→ ELSE
  │       │       └─→ // Other stores: Divide equally among employees
  │       │       └─→ equal_share = 30% × store_pool / total_employee_count
  │       │
  │       ├─→ [4.3] Calculate Manager Bonus (if applicable)
  │       │   │
  │       │   ├─→ IF (employee.is_manager == true)
  │       │   │   │
  │       │   │   ├─→ IF (achievement_pct >= 100%)
  │       │   │   │   └─→ manager_bonus = 3,000,000 VND
  │       │   │   │
  │       │   │   └─→ ELSE IF (achievement_pct >= 70% AND achievement_pct < 100%)
  │       │   │       └─→ manager_bonus = 750,000 VND
  │       │   │
  │       │   └─→ ELSE
  │       │       └─→ manager_bonus = 0
  │       │
  │       └─→ [4.4] Calculate Total Store Commission
  │           │
  │           ├─→ IF (employee.is_probation == true)
  │           │   └─→ // Probation employees only receive equal share portion
  │           │   └─→ total_store_commission = equal_share
  │           │
  │           └─→ ELSE
  │               └─→ // Regular employees receive full commission
  │               └─→ total_store_commission = individual_share + equal_share + manager_bonus
  │
  └─→ [STEP 5] Return Results as DataFrame
      │
      └─→ FOR EACH employee IN employees
          └─→ OUTPUT DataFrame Row: {
              ├─→ employee_code: String
              ├─→ full_name: String
              ├─→ seniority: Number (years)
              ├─→ is_manager: Boolean
              ├─→ is_probation: Boolean
              ├─→ working_day_count: Number
              ├─→ store_code: String
              ├─→ individual_share: Number (70% based on contribution)
              ├─→ equal_share: Number (30% share)
              ├─→ manager_bonus: Number
              │   ├─→ 3,000,000 if is_manager AND achievement >= 100%
              │   ├─→ 750,000 if is_manager AND 70% <= achievement < 100%
              │   └─→ 0 otherwise
              └─→ total_store_commission: Number
                  ├─→ equal_share (if is_probation == true)
                  └─→ individual_share + equal_share + manager_bonus (if is_probation == false)
          }

END

NOTES & CLARIFICATIONS:
═══════════════════════════════════════════════════════════════════════════

1. COMMISSION RATE STRUCTURE BY TIER (CUMULATIVE):

   IMPORTANT: Commission rates are ADDITIVE across tiers. Higher achievement
   means earning ALL lower tier rates PLUS the current tier rate on the
   corresponding revenue portions.

   Achievement 70-80%:
   • Full Price: 0.5% (all employees)
   • Discounted: 0.25% (all employees)

   Achievement 80-90% (CUMULATIVE - earns BOTH tier 70-80% AND 80-90%):
   • Tier 70-80% portion: Same as above
   • Tier 80-90% portion:
     - Senior (3+ years): 0.2% on full price only
     - Junior (< 3 years): 0.1% on full price only
     - No commission on discounted goods

   Achievement 90-100% (CUMULATIVE - earns tiers 70-80%, 80-90%, AND 90-100%):
   • Tier 70-80% portion: Same as above
   • Tier 80-90% portion: Same as above
   • Tier 90-100% portion:
     - Senior (3+ years): 0.2% on full price only
     - Junior (< 3 years): 0.1% on full price only
     - No commission on discounted goods

   Achievement 100%+ (SPECIAL RULE):
   • Tier 70-80% portion: Same as above
   • Tier 80-90% portion: Same as above
   • Tier 90-100% portion: Same as above
   • Tier 100%+ portion (ONLY on revenue EXCEEDING 100% target):
     - Senior (3+ years): 0.1% on full price only
     - Junior (< 3 years): 0.05% on full price only
     - No commission on discounted goods
   • Manager receives additional 3,000,000 VND bonus

   MANAGER BONUS STRUCTURE:
   • Achievement >= 100%: Manager receives 3,000,000 VND bonus
   • Achievement >= 70% and < 100%: Manager receives 750,000 VND bonus
   • Achievement < 70%: No commission (store not eligible)

2. SALES FILTERING BY STORE:
   - Employees can sell items from stores other than their assigned store
   - For commission calculation, ONLY sales from the employee's assigned store count
   - EXCEPTION: RHN and RWP are treated as the same store
     * Employees from RHN can include sales from both RHN and RWP
     * Employees from RWP can include sales from both RHN and RWP
   - All other stores: Only transactions matching the exact store_code are included
   - This ensures employees are only rewarded for sales in their home store

3. DISTRIBUTION METHOD:
   - 70% of pool distributed based on individual contribution
   - 30% of pool distribution:
     * For RHN store: Distributed based on working day contribution
       (employee working days / total working days of all employees)
     * For other stores: Distributed equally among all employees
       (divided by total employee count)
   - This balances performance-based and team-based rewards

4. ELIGIBILITY REQUIREMENTS:
   - Store must achieve at least 70% of target revenue from full-price goods
   - If full-price ratio is below target, discounted revenue must compensate
     at 200% ratio (i.e., 2 VND discounted = 1 VND full-price shortfall)

5. INPUT STRUCTURE:
   Frontend sends a JSON/Dictionary object containing:
   - store_code: Store identifier (e.g., "RHN")
   - store_target: Store's revenue target
   - store_fp_ratio_target: Target full-price ratio
   - query_date: {from_date, to_date} for the period
   - employees: Array of employee objects with:
     * employee_code: Unique identifier
     * full_name: Employee's full name
     * seniority: Tenure in years (determines Senior/Junior tier)
     * personal_target: Individual sales target
     * working_day_count: Days worked in period (for RHN distribution)
     * is_manager: Boolean flag for manager bonus eligibility
     * is_probation: Boolean flag for probation status (affects commission calculation)

   Derived parameters:
   - total_employee_count: COUNT(employees) - for equal distribution
   - total_working_days: SUM(working_day_count) - for RHN ratio calculation
   - actual_revenue, actual_full_price_revenue, actual_discounted_revenue:
     Queried from database based on store_code and query_date period

6. OUTPUT STRUCTURE:
   The service returns a DataFrame with the following columns:
   - employee_code: Unique employee identifier
   - full_name: Employee's full name
   - seniority: Years of service
   - is_manager: Boolean flag for manager status
   - is_probation: Boolean flag for probation status
   - working_day_count: Days worked in the period
   - store_code: Store identifier
   - individual_share: 70% of store pool based on employee contribution
   - equal_share: 30% of store pool (equal split or working day ratio for RHN)
   - manager_bonus: Tiered bonus for managers
     * 3,000,000 VND if is_manager AND achievement >= 100%
     * 750,000 VND if is_manager AND 70% <= achievement < 100%
     * 0 otherwise
   - total_store_commission: Total commission for the employee
     * equal_share (if is_probation == true)
     * individual_share + equal_share + manager_bonus (if is_probation == false)

7. PAYMENT TIMING:
   - Commission paid with the following month's salary
   - Only applies to commission from installment/deferred payment sales
     (for regular sales, commission is paid immediately)

8. PROBATION EMPLOYEE RULES:
   - Employees on probation (is_probation == true) receive significantly reduced commission
   - Probation employees ONLY receive:
     * Equal share (30% pool distribution)
   - Probation employees are NOT eligible for:
     * Individual share (70% based on contribution)
     * Manager bonus (even if is_manager == true)
   - This applies during the employee's probation period only
   - Once probation ends, employee receives full commission including individual share and manager bonus (if applicable)
